## Exercícios

1. Explique a diferença entre **Props** e **State**.

2. Qual é a função do Hook `useState()`?

3. Desenvolva um contador com botões para incrementar, decrementar e reiniciar o valor.

4. Crie um componente `Lampada` com um botão que alterne o estado entre **Ligada** e **Desligada**, exibindo a mensagem correspondente.

5. Implemente um componente `Carrinho` que apresente a quantidade de itens e possua botões para adicionar e remover produtos, impedindo que a quantidade fique negativa.

6. Modifique o componente `CardProduto` para exibir a mensagem **"Últimas unidades"** quando o estoque for menor ou igual a 3.

7. Pesquise a diferença entre **estado local** e **estado global** em aplicações React e escreva um resumo de, no mínimo, 10 linhas.
